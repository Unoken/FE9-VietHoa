# Fire Emblem: Path of Radiance — Bản Việt hóa

Bản Việt hóa của người hâm mộ, thực hiện bởi **Unoken**. Trang giới thiệu và hướng dẫn: https://unoken.github.io/FE9-VietHoa/

Tải patch ở mục **Releases**, hoặc patch ngay trên trang web. Repo này chỉ chứa trang web và file patch, không chứa game hay dữ liệu đĩa gốc.

Không liên quan tới Nintendo hay Intelligent Systems.
