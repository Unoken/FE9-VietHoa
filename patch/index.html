Chọn ảnh đĩa gốc

Trình duyệt này không có hộp chọn nơi lưu: ISO mới sẽ được tải xuống như một file thường. Chrome hoặc Edge trên máy tính cho trải nghiệm tốt nhất.

Lưu ý

  • Cần khoảng 1,5 GB trống trên máy. Giữ nguyên trang này cho đến khi patch xong.
  • Thời gian tùy thiết bị: máy tính thường chỉ khoảng một phút, điện thoại có thể mất 3–4 phút hoặc lâu hơn với máy yếu.
  • Chỉ cần chọn file game dạng ISO hoặc RVZ (dạng nén mặc định của Dolphin). File dạng khác: mở Dolphin, chuột phải vào game → Convert File… để đổi sang ISO hoặc RVZ.
  • Trang tự kiểm tra file của bạn có đúng bản game cần dùng không, và kiểm tra lại file sau khi patch.
  • Khi chơi trên Dolphin: vào Config → GameCube → System Language, chọn English.
  • Hãy lưu bằng save trong game (thẻ nhớ). Save state của Dolphin chỉ nên dùng tạm: nó không dùng chéo được giữa bản gốc và bản Việt hóa, giữa các phiên bản Việt hóa, và có thể hỏng khi cập nhật Dolphin. Save trong game của bản gốc dùng tiếp được với bản Việt hóa.
  • Không patch được trên web? Xem cách khác trong phần hướng dẫn.
